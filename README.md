## 👩‍💻 About The Project

Welcome to my **Java Practice Labs**! This repository documents my journey in mastering **Java Standard Edition (SE)**, demonstrating my ability to write clean, efficient, and well-structured code.

The project is organized into modular "labs," covering everything from **Object-Oriented Programming (OOP)** principles to advanced topics like **Generics, Stream API, and Serialization**. It serves as a comprehensive reference for my technical skills in software engineering.

---

## 🚀 Key Modules & Topics

The repository is structured into specific folders, each focusing on a core concept:

### 🔹 Java Basics & Logic
* **Control Flow:** `Basic-If-Else-Scanner`, `HelloWorld`
* **Simple Algorithms:** `Number-Guessing-Game`, `Student-Grade-Calculator`

### 🔹 Data Structures (Arrays & Collections)
* **Arrays:** `Array-Reverse-Print`, `City-Data-2D-Array`
* **Collections Framework:** `Collections-Utility-Methods` (Sorting, Shuffling), `Word-Frequency-Counter` (HashMap Analysis)
* **Simulations:** `Bus-Passenger-Simulation`

### 🔹 Object-Oriented Programming (OOP)
* **Core Concepts:** `OOP-Class-Basics`, `OOP-Constructor-Example`, `OOP-Inheritance-Basics`
* **Abstraction & Polymorphism:** `OOP-Abstraction-Interface`, `Interface-Polymorphism-Example`, `Shape-Drawing-System`
* **Design Patterns:** `OOP-Interface-Decoupling` (Separating Logic from UI)

### 🔹 Advanced Java Features
* **Generics:** `Generic-Class-Example`, `Generic-Shopping-Cart`, `Generic-Functional-Interface`
* **Nested Classes:** `Nested-Inner-Classes`
* **Java 8+:** `Java8-Stream-API`

### 🔹 Exception Handling & I/O
* **Exceptions:** `Custom-Exception-Handling`, `Exception-Propagation-Demo`
* **File Operations:** `File-IO-Operations`
* **Serialization:** `Serialization-Basics`, `Object-Serialization-Demo`

## 🛠️ How to Run

1.  **Clone the repository:**
    ```bash
    git clone [https://github.com/simaytaskin/Java-Practice-Labs.git](https://github.com/simaytaskin/Java-Practice-Labs.git)
    ```
2.  **Open in IDE:**
    Open the project in **IntelliJ IDEA** (recommended) or Eclipse.
3.  **Run Main Classes:**
    Each folder contains a `Main.java` file acting as an entry point. Navigate to the desired topic folder and run the `main` method.
